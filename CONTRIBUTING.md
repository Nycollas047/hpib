# Contributing · Contribuindo

**English** · [Português](#português)

## English

HPIB is a draft specification. The most valuable contributions right now are critiques, hardware evidence and references.

**Welcome**

| Type | What to include |
|---|---|
| Spec feedback | An issue citing the section and proposing a change |
| Hardware evidence | A capability descriptor (`schemas/capability-descriptor.schema.json`) plus logs for T02, T03, T09, T11 |
| Related work | Reference and a one-line difference from HPIB |
| New tasks or adapters | An issue first (RFC), then a pull request |
| Human-evaluation improvements | Rationale and, ideally, pilot data |

**Rules**

1. Released task versions are immutable; changes create a new version.
2. Do not commit private held-out variants, hidden tests or anything under NDA.
3. Hardware claims need evidence at a stated verification level (V0–V4).
4. Keep English and Portuguese documents equivalent; if you change one, change or flag the other.
5. By contributing you agree your work is released under the project license (Apache-2.0, decision D-01).

## Português

O HPIB é uma especificação em rascunho. As contribuições mais úteis agora são críticas, evidências de hardware e referências.

**Bem-vindo**

| Tipo | O que incluir |
|---|---|
| Feedback sobre a especificação | *Issue* citando a seção e propondo a mudança |
| Evidência de hardware | Descritor de capacidades (`schemas/capability-descriptor.schema.json`) e logs de T02, T03, T09, T11 |
| Trabalhos relacionados | Referência e uma linha com a diferença para o HPIB |
| Novas tarefas ou adaptadores | Primeiro uma *issue* (RFC), depois um *pull request* |
| Melhorias na avaliação humana | Justificativa e, de preferência, dados de piloto |

**Regras**

1. Versões de tarefas publicadas são imutáveis; mudanças criam nova versão.
2. Não envie variantes privadas de retenção, testes ocultos nem nada sob NDA.
3. Afirmações sobre hardware exigem evidência em um nível de verificação declarado (V0–V4).
4. Mantenha os documentos em inglês e português equivalentes; se alterar um, altere ou sinalize o outro.
5. Ao contribuir, você concorda que seu trabalho seja liberado sob a licença do projeto (Apache-2.0, decisão D-01).
